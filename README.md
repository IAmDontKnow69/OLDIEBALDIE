# OLDIEBALDIE Bot

This repository contains the OLDIEBALDIE Discord bot for CS2 team management.

Quick start

1. Copy `.env.example` to `.env` and fill in your values.
2. npm install
3. npm start

The bot expects the following environment variables:
- DISCORD_TOKEN
- FACEIT_API_KEY
- GUILD_ID
- TEAM_LOGO_URL (optional)
- CATEGORY_MATCHDAY_ID (optional)

Security: never commit your .env or secrets.
